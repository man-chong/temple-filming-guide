# 廟宇拍攝申請人須知
### Temple Filming — what the published rules say before you apply

一個單頁、只在瀏覽器內運作的導覽，整理華人廟宇委員會已公布的拍攝條件，
供準備遞交拍攝申請的人在遞交前參考。

A single-page, browser-only guide setting out what the Chinese Temples
Committee's published rules say to somebody preparing a temple filming
application.

不作批核，亦不代表委員會發言。頁面不接受申請、不作任何決定，並不收集任何個人資料——
所有計算都在使用者自己的瀏覽器內完成，不儲存、不傳送任何輸入。最後指向委員會的正式表格。

It accepts no applications, makes no determination, speaks for nobody, and
collects no personal information. Everything is computed in the visitor's own
browser; nothing is sent or stored. It ends by directing the applicant to the
Committee's own form.

Every rule shown carries its source document and clause. Anything stated in
none of them does not appear.

## 關於此檔案 · About this file

`index.html` 由本機的建置程序產生，請勿直接修改。建置前會先驗證廟宇分類數目、
條文路由、費用下限及用語，任何一項不通過即不會輸出檔案。建置原始碼不在此存放庫內。

`index.html` is generated. A local build verifies the temple categories, the
rule routing, the fee boundaries and the permitted wording, and writes nothing
if any check fails. The build source is not published here.
